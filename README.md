# exactly

مكتبة برمجية مكتوبة بلغة Go.

## الوصف
هذا المشروع عبارة عن مكتبة/أداة برمجية بلغة Go. سيتم تحديث هذا القسم بمزيد من التفاصيل حول الغرض والاستخدام.

## المتطلبات
- [Go](https://go.dev/) الإصدار 1.21 أو أحدث

## التثبيت

```bash
go get github.com/asalomeri/exactly
```

## الاستخدام

```go
package main

import (
	"fmt"
	"github.com/asalomeri/exactly"
)

func main() {
	fmt.Println("مرحبًا من exactly!")
}
```
